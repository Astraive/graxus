# Graxus Next Phase Plan

## Executive Summary

The previous session completed 37 items across security, bugs, features, and quality. This plan covers the next high-impact improvements: **incremental indexing**, **diff command**, **shell completions**, **more integration tests**, and **import/call resolution improvements**.

---

## 1. Incremental Indexing (`graxus update`)

**Goal:** Actually re-index only changed files instead of full re-scan.

### Current State
- `graxus update` exists but falls back to full re-index
- `scanner::compute_diff` exists and works
- `scanner::load_saved_files` / `save_saved_files` exist
- Codemap/DocGraph have no `update()` method — must rebuild from scratch

### Implementation
1. Add `CodemapBuilder::update(existing, new_code_files, removed_paths)` to `crates/graxus-codemap/src/lib.rs`
   - Remove symbols/imports/calls for deleted files
   - Re-extract symbols/imports/calls for modified/new files
   - Merge with existing graph
2. Add `DocGraph::update(existing, root, config)` to `crates/graxus-docgraph/src/lib.rs`
   - Remove nodes/edges for deleted docs
   - Re-parse modified/new docs
   - Merge with existing graph
3. Update `cli/src/commands/update.rs` to use the new incremental methods
4. Update SQLite index incrementally (delete old rows, insert new)

### Files
- `crates/graxus-codemap/src/lib.rs` — add `update()` method
- `crates/graxus-docgraph/src/lib.rs` — add `update()` method
- `crates/graxus-index/src/sqlite.rs` — add `delete_file_data()` method
- `cli/src/commands/update.rs` — wire up incremental flow

## 5. Import Resolution Improvements

**Goal:** Better resolve Rust `crate::` paths and TS relative imports.

### Current State
- Basic resolution exists in `resolver/import_resolver.rs`
- Rust: handles `crate::` but not `super::` or `self::`
- TS: handles `./foo` but not `../foo` or path aliases

### Improvements
1. Rust: handle `super::`, `self::`, and `use crate::` with nested paths
2. TypeScript: handle `../` relative paths, `@/` aliases, and `index.ts` resolution
3. Add confidence scores based on resolution quality

### Files
- `crates/graxus-codemap/src/resolver/import_resolver.rs` — enhance resolvers
